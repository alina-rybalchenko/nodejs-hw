## 03-validation

Express server with MongoDB, full CRUD, **pagination**, **filtering** and **request validation** using Celebrate.

- GET /notes with `page`, `perPage`, `tag` and `search` query parameters
- GET /notes/:noteId
- POST /notes
- PATCH /notes/:noteId
- DELETE /notes/:noteId

Live Demo:
https://zero3-validation-ajsv.onrender.com
